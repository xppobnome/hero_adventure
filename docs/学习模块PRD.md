# 《英雄闯关计划》学习模块 PRD

## 1. 项目信息

- **文档语言**：中文
- **技术栈**：Flutter + Riverpod + Hive（沿用现有架构）
- **项目名**：hero_adventure
- **新增依赖**：`flutter_tts`（语音播放）、`speech_to_text`（语音识别）
- **原始需求复述**：在现有奥特曼主题儿童习惯养成 App 中，新增「学习模块」，覆盖 **学拼音 / 识字 / 学英语** 三类跟读学习任务。软件播放发音 → 儿童跟读 → 语音识别并判定对错 → 达标发放奖励。本轮交付：拼音完整闭环 + 识字/英语「框架 + 常见字/词表」。

## 2. 产品定义

### 2.1 产品目标

1. **复用数学闯关的成功范式**：在「家长配置任务 → 儿童进入答题/跟读 → 达标发奖励」的既有闭环上，扩展出三类语音跟读学习任务，保持交互与视觉一致性。
2. **可落地的跟读闭环**：借助系统 TTS（播放）+ 系统语音识别（采集）+ 模糊匹配（判分），在不过度依赖第三方语音评测服务的前提下，实现「读一遍 → 读一遍 → 判对错」的最小可用闭环。
3. **内容分模块渐进交付**：拼音模块完整可用；识字/英语模块先搭好框架与字词表，供后续迭代填充优化。

### 2.2 用户故事

**家长视角**

1. 作为家长，我想给孩子下达一个「每天跟读拼音」任务（可选声母/韵母/整体认读音节、每天数量、达标阈值），让孩子像做数学题一样每天练发音。
2. 作为家长，我想给孩子下达「识字」或「学英语」任务，从儿童常见字/小学单词表中挑选内容，孩子跟读后自动判对错。
3. 作为家长，我想沿用现有的奖励机制（EXP/能量币），让孩子完成跟读达标后即时获得奖励，无需我逐一人工审核。

**儿童视角**

4. 作为儿童，我点开「拼音闯关」任务后，能看到一个大大声母/韵母，点「播放」听到标准发音，我跟着读，读对了看到绿色对勾和英雄夸奖，读错了可以再读一遍。
5. 作为儿童，我在识字/英语闯关里看到带拼音的汉字或英文单词，软件读一遍、我读一遍，答对后攒满进度就能「发动光线」获得奖励。

## 3. 需求池（P0 / P1 / P2）

> 优先级约定：P0 = 本轮必须（闭环可用）；P1 = 本轮应做（体验完整）；P2 = 后续迭代（可选优化）。

### 3.1 通用（三个模块共用）

| 优先级 | 需求点 |
| --- | --- |
| P0 | 任务模型扩展：新增学习任务类型及配置字段（`learnSubject / learnScope / learnCount / learnPassPercent`），Hive 持久化向后兼容 |
| P0 | 儿童端入口路由：任务卡片识别学习任务后进入统一「跟读闯关」界面（参考 `MathQuizView` 的入口判断） |
| P0 | 跟读交互主流程：播放 → 跟读 → 识别 → 判分 → 重试/下一题 → 达标发奖励 |
| P0 | 达标判定与发奖：达到「通过百分比」后调用现有 `addCheckIn` + `updateChildExp`，防重复发奖（当日已完成仅练习） |
| P1 | 每项跟读的「对/错」即时反馈（绿色/红色 + 音效），儿童可对单项「重读」 |
| P1 | 语音权限引导：首次进入提示授予麦克风权限；识别失败/无网络时的友好降级提示 |
| P2 | 单次练习的历史成绩记录（正确率、跟读时长），供家长端查看 |

### 3.2 拼音模块

| 优先级 | 需求点 |
| --- | --- |
| P0 | 拼音字库全表：声母 23 + 韵母 24 + 整体认读音节 16（共 63 项），带分类标签 |
| P0 | 范围选择：家长可限定「声母 / 韵母 / 整体认读音节 / 全部」 |
| P0 | 播放标准发音（`flutter_tts`，中文）；识别文本与目标拼音做**声调无关**近似匹配判分 |
| P1 | 显示拼音分类与进度（如「韵母 3/10」） |
| P2 | 发音示范补充：对易混声母（z/zh、c/ch 等）提供对比卡片 |

### 3.3 识字模块

| 优先级 | 需求点 |
| --- | --- |
| P0 | 识字框架：与拼音共用同一跟读界面，仅切换内容数据源与图标 |
| P0 | 常见字表：约 200–300 个小学低年级常见字，每字带拼音、可跟读（字或词均可） |
| P1 | 展示拼音 + 大字卡片；识别文本与「字/词拼音」做声调无关匹配 |
| P2 | 按年级/册次分类（一年级上/下），家长可选定范围 |
| P2 | 例句/组词提示，辅助儿童理解字义 |

### 3.4 英语模块

| 优先级 | 需求点 |
| --- | --- |
| P0 | 英语框架：与拼音共用同一跟读界面，识别语言切换为英文 |
| P0 | 小学单词表：约 200–300 个小学（3–6 年级）常见单词，带中文释义 |
| P1 | 展示单词 + 中文释义；识别文本与单词做大小写/空格不敏感匹配 |
| P2 | 按年级/主题（颜色、数字、动物、家庭成员等）分类 |

## 4. 跟读学习完整交互流程

单个跟读条目（拼音/字/词）的主流程：

```
进入跟读闯关
   │
   ▼
初始化本日条目列表（按 learnCount 从字库随机抽取，去重）
   │
   ▼
┌──────── 当前条目卡片（大字号展示目标） ────────┐
│  1) [播放] 软件读一遍 (flutter_tts)           │
│  2) 儿童点「跟读」→ 麦克风开始录音 (speech_to_text) │
│  3) 儿童朗读，识别结束返回文本                    │
│  4) 模糊匹配判定对错                             │
│     ├─ 对：绿色对勾 + 胜利/正确音效，自动进入下一题  │
│     └─ 错：红色提示，可「再读一遍」(不限次数)      │
│  5) [下一题] 或自动跳转                          │
└──────────────────────────────────────────────┘
   │
   ▼
全部条目完成后 → 计算正确率
   │
   ├─ 达到 learnPassPercent（且当日未完成）：
   │     播放奖励动画 + 发放 EXP/能量币 + 写打卡记录
   ├─ 未达标：提示「还差一点」，可「重做一遍」（重新抽题）
   └─ 当日已完成：仅练习，不重复发奖
```

**关键状态机要点**

- 每个条目维护独立状态：`未读 / 播放中 / 录音中 / 识别中 / 正确 / 错误`。
- 判分采用**模糊匹配**：拼音/识字做声调无关近似（去除声调符号、忽略空格后比较），英语做大小写与空格不敏感比较。
- 识别异常（超时、无识别结果、无网络、权限拒绝）视为「本次无效」，允许重试，不计为错误，避免误伤儿童。
- 达标判定沿用数学闯关逻辑：`正确数 >= ceil(总数 × learnPassPercent / 100)`。

## 5. 字库 / 词库范围说明

### 5.1 拼音全表（P0，完整内置）

| 分类 | 数量 | 内容 |
| --- | --- | --- |
| 声母 | 23 | b p m f d t n l g k h j q x zh ch sh r z c s y w |
| 韵母 | 24 | 单韵母 a o e i u ü；复韵母 ai ei ui ao ou iu ie üe er；前鼻韵母 an en in un ün；后鼻韵母 ang eng ing ong |
| 整体认读音节 | 16 | zhi chi shi ri zi ci si yi wu yu ye yue yuan yin yun ying |

- 共 63 项，以静态常量表（Dart `const` List）内置，不依赖网络。
- 每项结构：`{ text: 'b', pinyin: 'b', category: 'shengmu' }`；整体认读音节以完整音节为 `text`。

### 5.2 识字常见字表（P0，约 200–300 字）

- **来源**：人教版（部编版）小学语文一年级上/下册生字表，取高频常用字；可参考《现代汉语常用字表》一级常用字（2500 字）中前 300 高频字交叉筛选。
- **数量**：本轮内置 200–300 字（建议先 250 字左右，覆盖一年级常见生字）。
- **字段**：`{ char: '人', pinyin: 'rén', word: '大人', wordPinyin: 'dà rén' }`；跟读目标可以是单个字，也可用组词（字词均可）。
- **来源标注**：需在数据文件注释中注明依据，避免版权争议（建议使用通用生字表/公开教材大纲，不直接照搬教材排版）。

### 5.3 英语小学单词表（P0，约 200–300 词）

- **来源**：小学英语（三年级起点）人教版/外研版 3–6 年级核心词汇，结合剑桥少儿英语 Starter/Movers 高频词，取前 300 高频词。
- **字段**：`{ word: 'apple', meaning: '苹果' }`。
- **来源标注**：同识字，使用公开大纲/高频词表。

## 6. 任务配置项（家长端）

参考数学任务字段设计，建议**新增统一学习任务类型** `learn`（与现有 `math` 并列），避免三个模块各写一套重复配置。

### 6.1 模型字段扩展（`lib/data/models/task.dart`）

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `learnSubject` | String | `'pinyin'` | 学科：`pinyin` / `hanzi` / `english` |
| `learnScope` | String | `'all'` | 内容范围：拼音 `shengmu/yunmu/zhengti/all`；识字/英语预留 `grade1/.../all`（本轮识字/英语可先统一 `all`） |
| `learnCount` | int | `10` | 每天跟读条目数量 |
| `learnPassPercent` | int | `80` | 通过阈值（百分比）。**语音识别准确率波动大，默认建议 80%，低于数学的 100%** |

> 同时新增 `bool get isLearnTask => type == 'learn';` 与 `typeLabel`/`cycleDescription` 分支，保持与 `isMathTask` 一致。

### 6.2 家长端编辑（`task_edit_view.dart`）

- 新增「学习跟读（拼音/识字/英语）」开关（或与数学题并排的「学习类型」选择），打开后展示：
  - **学科选择**：学拼音 / 识字 / 学英语（ChoiceChip 三选一）。
  - **内容范围**：拼音显示「声母/韵母/整体认读音节/全部」；识字/英语本轮先显示「全部（常见字/词表）」，范围细分留 P2。
  - **每天跟读数量**：预设 `5 / 10 / 20` + 自定义（复用数学题数量选择交互）。
  - **达标阈值**：预设 `60% / 80% / 100%` + 自定义（复用数学题阈值选择交互）。
- 保存时按 `learnSubject` 写入对应字段，`type` 统一为 `learn`。

### 6.3 儿童端入口（`child_adventure_view.dart`）

- 任务卡片判断 `task.isLearnTask` 后，直接 `Navigator.push` 进入统一跟读界面 `LearnQuizView(childId, task)`，与 `MathQuizView` 并列。
- 卡片左侧图标按学科区分：拼音 `Icons.record_voice_over` / 识字 `Icons.text_fields` / 英语 `Icons.abc`（与现有怪兽图标、数学图标风格一致）。

## 7. UI 设计要点

延续数学闯关的奥特曼星空风格，保持儿童友好与平板横屏适配：

1. **星空背景 + 大卡片**：沿用 `UltramanStarfield()` 背景；目标字/词用**超大字号**（拼音/汉字 ≥ 80px、英文 ≥ 64px）居中卡片展示，卡片白底圆角 + 主题色描边。
2. **核心操作区**：底部固定「播放（📢 听一遍）」「跟读（🎤 我读一遍）」「下一题」三个大按钮；录音时麦克风图标变为红色脉冲动效，识别结果以文字气泡展示。
3. **对错反馈**：正确绿色对勾 + 胜利音效；错误红色提示 + 轻提示「再试一次」，不打击儿童。
4. **进度可视化**：顶部说明条展示「学科 · 范围 · 共 N 项 · 正确率 X%」（对齐数学题的 header 结构）。
5. **横屏适配**：与数学闯关一致，`isLandscape` 时左侧条目/进度、右侧操作按钮，`maxWidth` 居中（横屏 ≤ 1080，竖屏 ≤ 720），避免 `screenutil` 在平板上的放大溢出问题。
6. **奖励动画**：达标复用 `CelebrationEffect`（「太棒了！」+ 获得 EXP/币），保持一致仪式感。

## 8. 待确认问题

1. **达标阈值默认值**：语音识别准确率受设备/环境/网络影响大，拼音/识字默认 80%、英语默认 60% 是否合适？是否需要家长可调、还是固定放宽？
2. **识字/英语范围细分是否本轮做**：识字按「一年级上/下」、英语按「年级/主题」分类是否留到 P2，本轮统一用「全部常见字/词表」？
3. **跟读判分的严格程度**：拼音是否允许「声母韵母分开判」还是必须整体一致？同音异形（如 `b` 被识别成英文 `bee`）如何规避误判？
4. **英语 TTS 音源**：`flutter_tts` 系统音源在部分安卓设备缺英文发音时，是否需要指定 `en-US` locale 并做可用性兜底提示？
5. **离线场景**：`speech_to_text` 需联网（依赖设备语音服务），断网时是否提供「跳过跟读 / 手动标记完成」的兜底，还是直接提示「当前无法识别」？
6. **内容版权**：识字/英语字词表来源是否仅需公开大纲级清单即可，还是需要内部整理一份正式版权来源说明？
7. **三个模块是否共用同一个 `learn` 类型**：已推荐统一类型，是否确认（避免未来模块增加时模型字段继续膨胀）？

## 9. 交付范围小结（本轮）

- **拼音**：完整闭环（63 项全表 + 跟读 → 识别 → 判分 → 重读 → 达标发奖励）。
- **识字**：共用跟读框架 + 约 200–300 字带拼音字表（字/词均可）。
- **英语**：共用跟读框架 + 约 200–300 小学单词表（带中文释义）。
